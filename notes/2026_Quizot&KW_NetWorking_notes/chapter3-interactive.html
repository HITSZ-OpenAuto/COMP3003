第 3 章 数据链路层与局域网

按课件与作业整理：链路层服务、差错检测、可靠传输、MAC 协议、以太网、交换机、VLAN 与 PPP。

Framing / Byte & Bit Stuffing CRC / Hamming Distance Stop-and-Wait / GBN / SR CSMA/CD Ethernet / Switch / VLAN

考点地图

3.1 链路层服务

负责相邻结点间数据报传输，核心功能包括组帧、物理寻址、流量控制、差错控制和访问控制。

3.2 差错检测

奇偶校验、Internet 校验和、CRC 是常见检错码；汉明距离决定检错/纠错能力。

3.3 可靠传输

停等协议简单但利用率低；流水线和滑动窗口提高利用率；GBN 累积确认，SR 单独确认并缓存乱序帧。

3.4 MAC 协议

信道划分、随机访问和轮转访问三类。CSMA/CD 是以太网典型随机访问协议。

3.5 局域网

MAC 地址用于局域网接口寻址；以太网帧数据字段 46-1500B；交换机自学习并选择性转发。

作业重点

作业一：滑动窗口吞吐量、GBN 窗口大小与超时重传。作业二/三：以太网帧接收、最小载荷填充。

可靠传输

停等/滑动窗口利用率

U = min(1, Ws * tframe / (tframe + RTT + tack))

窗口与序号空间

Ws + Wr <= 2^k; GBN: Ws <= 2^k - 1; SR: W <= 2^(k-1)

GBN 累积确认与超时重传

输入已发送帧范围和收到的 ACK，按 GBN 累积确认规则判断超时后重传哪些帧。

组帧与检错

比特填充

定界符 01111110。发送端在有效载荷中每遇到连续 5 个 1，就插入 1 个 0。

CRC 余数

R = remainder(D * 2^r / G)

PPP 字节填充

异步 PPP 中，0x7E 转为 0x7D 0x5E；0x7D 转为 0x7D 0x5D。

检错/纠错能力

检 r 位错: ds >= r+1; 纠 r 位错: ds >= 2r+1

以太网与交换机

以太网填充与帧长

前导码通常不计入帧长；目的 MAC + 源 MAC + 类型共 14B，FCS 为 4B，数据字段至少 46B。

CSMA/CD 最小帧长

Lmin / R = 2dmax / V

交换机转发判断

交换机先学习源 MAC 与输入端口，再查目的 MAC；未知则泛洪，目的在同端口则丢弃。

Homework First

作业与期末考点地图

作业一

基础公式与体系结构
  • 五层体系结构与 PDU: 比特、帧、数据报、段、报文。
  • 波特率与比特率: Rb = RB log2 M。
  • 存储转发时延: 传输、传播、处理时延的叠加。
  • 报文交换 vs 分组交换: 分组可流水线，常更快。
  • 滑动窗口吞吐量: U = Ws * tf / (tf + RTT)，满利用时求窗口。

关联章节: 第1章 / 第2章 / 第3章

作业二

网络层核心
  • IPv4 首部字段: IHL、Total Length、ID、Flag/Offset、TTL、Protocol、Checksum、源/目的 IP。
  • 最长前缀匹配: 多个匹配时选前缀最长项，主机路由 /32 比默认路由 /0 更具体。
  • 子网划分: 借位、掩码、网络号、广播地址、可用地址范围。
  • NAT: 出站改源 IP/端口，回包按 NAT 表改目的 IP/端口。
  • RIP: 距离向量、下一跳、跳数、不可达距离 16。
  • IPv6: 完整写法、隧道外层 IPv4 首部、分片计算。

关联章节: 第4章

作业三

TCP 与应用层
  • TCP Reno: BDP 求最大窗口，平均窗口 0.75W，平均吞吐量，恢复时间。
  • C/S 与 P2P 分发: Dcs 与 Dp2p 公式，对比随 N 增长的扩展性。
  • IP/TCP 报文分析: 源/目的 IP、三次握手、以太网填充、应用数据长度、TTL 推路由器数。
  • DNS: 递归+迭代查询过程，A/NS/MX 记录添加，缓存带来的延迟降低。
  • SMTP/MIME: 三阶段，TCP/25，MIME 让二进制附件经 Base64 等编码传输。

关联章节: 第5章 / 第6章

# 2026 年 AISZ-23 计算机网络复习资料

本目录收录计算机网络第 1–7 章的总结、交互式复习页、详细讲解、知识清单和章节测试。

## 内容说明

- [计算机网络复习总览](index.html)：第 1–7 章总结页的统一入口
- `chapter1-interactive.html` 至 `chapter3-interactive.html`：第 1–3 章交互式复习页
- `chapter3-detail.html` 至 `chapter6-detail.html`：第 3–6 章详细讲解
- [知识清单](知识清单/Readme.md)：Chapter 1–7 的分章知识清单
- [章节测试](章节测试/Readme.md)：Chapter 1–7 的交互式自测

## 使用方式

1. 下载本目录并保持现有文件结构不变。
2. 用浏览器打开 `index.html`，从总览进入各章总结、交互页和详细讲解。
3. 按需打开 `知识清单/` 与 `章节测试/` 中同章 HTML 文件，先复习知识点，再完成自测。
4. 页面无需安装依赖；部分公式使用 MathJax 渲染，首次加载时需要联网。

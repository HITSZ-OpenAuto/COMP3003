知识点总结

  • 网络层提供主机到主机的逻辑通信，将传输层 segment 封装进 IP datagram。
  • 核心功能是转发和路由: 转发是本路由器输入端口到输出端口的局部动作，路由是端到端路径选择。
  • 虚电路网络先建立逻辑连接，分组携带 VC ID；数据报网络每个分组独立携带目的地址。
  • 路由器输入端口执行物理/链路/网络层处理与查表，交换结构把分组送到输出端口。
  • 输出端口可能出现排队、调度和丢包，缓冲区并不能无限消除拥塞。
  • 转发表由路由算法/协议生成，实际转发按最长前缀匹配选择最具体表项。
  • IPv4 首部最小 20B，字段包括版本、首部长度、TOS、总长度、标识、标志、片偏移、TTL、协议、首部校验和、源/目的 IP。
  • 总长度字段 16 bit，表示 IP 首部加数据的总字节数。
  • TTL 每经过一个路由器减 1，可用于根据初始 TTL 和到达 TTL 推断经过路由器数。
  • 协议字段指示上层协议，例如 TCP=6、UDP=17、ICMP=1。
  • 链路 MTU 小于 IP 数据报长度且 DF=0 时，路由器可以分片；重组只在目的主机完成。
  • 同一原始数据报的所有分片复制相同标识字段。
  • 片偏移以 8B 为单位，除最后一片外，每片数据长度通常取不超过 MTU-20 的最大 8B 倍数。
  • DF=1 且长度超过 MTU 时路由器丢弃分组，并通常向源主机发送 ICMP 差错报文。
  • IP 地址与接口关联，不是与整台路由器关联。
  • 子网是不跨越路由器即可互相物理连通、拥有相同网络前缀的一组接口。
  • 子网掩码网络位为 1、主机位为 0；CIDR 写作 a.b.c.d/x。
  • 路由聚合要求共同前缀、相同下一跳/接口，并避免产生路由黑洞；转发时仍遵循最长前缀匹配。
  • ARP 在同一 LAN 内由 IP 地址解析 MAC 地址，请求广播、应答单播，节点维护带 TTL 的 ARP 表。
  • 跨 LAN 通信时 IP 源/目的地址端到端不变，每一跳链路层源/目的 MAC 会变化。
  • DHCP 采用 Discover/Offer/Request/ACK 四步，基于 UDP，常用广播，返回 IP、掩码、默认网关、DNS。
  • ICMP 支持差错报告和网络探询，traceroute 利用 TTL 超期与目的端口不可达报文。
  • NAT 将内网源 IP/端口映射为公网 IP/端口，维护 NAT 表；返回报文按表项改写目的 IP/端口。
  • 链路状态算法掌握全局拓扑和费用，典型为 Dijkstra；OSPF 属于链路状态协议。
  • 距离向量算法基于 Bellman-Ford，与邻居交换距离向量；RIP 属于距离向量协议。
  • RIP 度量是跳数，最大 15，16 表示不可达，通常每 30 秒向邻居通告。
  • OSPF 在 AS 内泛洪链路状态通告，可分层为区域和主干区。
  • BGP 是 AS 间路由协议，基于 TCP 会话交换路径向量，关注可达性和策略。
  • IPv6 地址 128 bit，基本首部固定 40B，移除首部校验和，选项移到扩展首部。
  • IPv6 基本首部不允许路由器分片，路径 MTU 问题通过 ICMPv6 Packet Too Big 等处理。
  • IPv6 压缩可用 :: 表示连续 0，但一个地址中只能使用一次。
  • 隧道技术把 IPv6 数据报作为 IPv4 数据报载荷穿越 IPv4 网络。

公式与判定

IPv4 首部长度
IHL * 4 bytes

IHL=5 时首部为 20B。

IP 数据长度
data = total length - header length

作业二第 1 题核心。

最大分片数据
d = floor((MTU - 20) / 8) * 8

默认无 IP 选项时。

分片数
n = ceil((L - 20) / d)

L 是原 IP 数据报总长度。

片偏移
offset_i = (i-1) * d / 8

偏移字段以 8B 为单位。

可用主机数
2^(32-prefix) - 2

普通单播子网，排除网络地址和广播地址。

易错点

  • 最长前缀匹配不是找第一个匹配，而是找前缀最长的匹配。
  • 分片后的标识字段相同，不是各不相同。
  • 片偏移单位是 8B，不是 1B。
  • 重组在目的主机完成，不在中间路由器完成。
  • NAT 出站通常改变源 IP/端口，目的 IP 不变；入站返回报文通常改变目的 IP/端口。
  • 默认路由应写作 0.0.0.0/0，不是 0.0.0.0/32。
